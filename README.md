# PlanetA3 Agent

A modern AI SaaS website and backend API for PlanetA3 Agent, inspired by premium AI product landing pages.

## Stack
- Frontend: React + Vite
- Backend: Express
- Styling: custom CSS

## Run locally

1. Install dependencies:
   npm install
2. Start app:
   npm run dev
3. Open http://localhost:5173

## API endpoints
- GET /api/health
- GET /api/site-data
- POST /api/contact
- POST /api/demo-request
- POST /api/auth/demo-login

## Production build

npm run build
